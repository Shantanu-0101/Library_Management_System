# Library Management System 
## Tech Stack:
- Python
- Flask
- SQLAlchemy
- SQLite
- Bootstrap
- JavaScript

## Features:
- Built a full-stack web app with role-based portals for students  and admin, including approval workflows for book
requests  and student registration
- Automated fine calculation on book return with overdue  tracking and an admin dashboard with Chart.js analytics
- Implemented Excel bulk-upload, live search, and responsive  UI supporting both mobile and desktop views
